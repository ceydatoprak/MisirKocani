# Mısır Soyma Oyunu

Unity ve C# kullanılarak geliştirilmiş mobil oyun prototipi.

Bu proje, oyun geliştirme stajım sırasında geliştirdiğim ilk Unity projelerimden biridir. Temel amaç, mısır yapraklarını açıp taneleri sürükleyerek soyma mekaniği oluşturmaktı.

## Özellikler

- Dokunma ve sürükleme ile mısır soyma
- Yaprak açılma ve düşme animasyonları
- Fizik tabanlı mısır taneleri
- Ses efektleri
- Mobil titreşim geri bildirimi
- Soyulma ilerlemesini gösteren progress bar
- Dinamik tane yerleşimi

## Kullanılan Teknolojiler

- Unity
- C#
- Unity Physics
- Unity UI
- Git / GitHub

## Not

Bu proje staj sürecinde geliştirilmiş bir oyun prototipidir.
